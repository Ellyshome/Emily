## 🐛 发现的问题 - 权限管理相关

### Issue 1: 权限拦截尚未生效
**状态**: ⏳ 待 Core 集成
**优先级**: 高
**说明**: 当前版本权限系统尚未完全集成到消息处理流程中，所有用户消息均被处理，无权限拒绝现象。

**验证方法**:
- 访客发送"查看系统配置"，预期拒绝，但实际正常处理
- 所有权限级别的用户都得到相同的 Mock 响应，无差异

**建议集成点**:
1. 在 `handle_message` 入口增加权限检查
2. 根据用户 permission_level 决定是否接管/拒绝
3. 公开信息白名单机制

---

### Issue 2: 用户 IM 绑定需要对齐
**状态**: ⚠️ 待修复
**优先级**: 中
**说明**: 测试用户 ID 与 user_im_bindings 表的 im_user_id 需保持一致，否则每次会创建新用户。

**当前现象**:
- Docker 日志显示 "Auto-created user" 频繁出现
- 每次发送消息都创建新用户记录，权限数据无法关联

**修复方案**:
1. 修改 SQL 脚本，确保 users.id 与 user_im_bindings.im_user_id 一致
2. 或者修改 tester.py，使用 username 作为 sender_id

---

### Issue 3: permission_audit_log 审计表未验证
**状态**: ⏳ 待验证
**优先级**: 中
**说明**: 需要验证权限操作是否正确写入审计日志表。

**检查项**:
- 权限拒绝时是否记录
- 敏感操作是否记录
- 访问来源 IP 是否记录
