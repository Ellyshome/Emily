# Emily 元认知模块 — 实施计划

> **版本**：V3（对齐需求规格 V3）
> **需求文档**：[自我认知需求规格.md](自我认知需求规格.md)

---

## 设计原则

1. **独立脚本 + 薄聚合**：每个脚本可独立执行 + `--dry-run`
2. **按模块实现不分期**：模块间通过数据库和文件接口衔接
3. **项目初始化四层模型**：T1→T2→T3→T4，23 项必备项已定义
4. **冷启动自检邮件送达**：T1 必备管理员账户+邮箱保障闭环

---

## 模块实现顺序

| 模块 | 交付物 | 依赖 | 可独立验证 |
|------|--------|------|-----------|
| **M1 数据模型** | ProjectWorldBook ORM + Repo + init_db | 无 | 查表确认创建 |
| **M2 世界书构建** | `build_world_book.py` + ProjectWorldBookBuilder | M1 | `--dry-run` + `--project-id` |
| **M3 初始化检查** | `check_initialization.py` + 四层初始化逻辑（23项） | M1 | `--dry-run` + `--project-id` |
| **M4 认知偏差检测** | `detect_cognition_drift.py` + CognitionDriftDetector | M1+M2 | `--dry-run` + `--project-id` |
| **M5 世界书增量更新** | `update_world_book.py` + ProjectWorldBookService | M1+M2+M4 | `--dry-run` + `--project-id` |
| **M6 Session prompt 生成** | `generate_session_prompt.py`（世界书+规则书） | M1 | `--dry-run` + `--user-id` |
| **M7 规则书** | `emily-data/rules/规则书.md` + 加载逻辑 | 无 | 人工审阅 |
| **M8 EmilyCore 集成** | `_init_project_awareness()` + SessionContext 注入 + 规则书加载 | M2+M3+M6+M7 | 重启容器 + emy-test |
| **M9 调度器集成** | ProjectWorldBookUpdateHandler + `cognition_cycle.py` | M4+M5 | 手动触发调度器 |
| **M10 进化闭环集成** | cognition_drift 第 10 数据源 | M4+M9 | 运行 InsightGenerator |
| **M11 V1 整合** | self_check 保留 + cold_start 薄聚合（含邮件通知） | M2+M3 | 独立运行 cold_start |

---

## 独立脚本清单

| # | 脚本 | 职责 | 关键参数 |
|---|------|------|---------|
| 1 | `build_world_book.py` | 构建/重建单个项目的世界书 | `--project-id` `--layer` `--dry-run` |
| 2 | `detect_cognition_drift.py` | 检测世界书与实际数据的偏差 | `--project-id` `--all` `--dry-run` |
| 3 | `update_world_book.py` | 根据偏差增量更新世界书 | `--project-id` `--all` `--dry-run` |
| 4 | `check_initialization.py` | 检查项目初始化层级和缺失项 | `--project-id` `--all` `--dry-run` |
| 5 | `generate_session_prompt.py` | 生成 Session prompt（世界书+规则书） | `--user-id` `--dry-run` |
| 6 | `self_check.py` | 系统级自检（复用 V1） | `--dry-run` |

**薄聚合**：

| # | 脚本 | 串联逻辑 |
|---|------|---------|
| 7 | `cold_start.py` | self_check → check_initialization → build_world_book → 邮件通知 |
| 8 | `cognition_cycle.py` | detect_cognition_drift → update_world_book → 汇总日志 |
