> **基于**：[邮箱控制模块-完整需求规格.md](邮箱控制模块-完整需求规格.md)
> **日期**：2026-06-27
> **版本**：v1.0
> **范围**：仅提供模块化邮件收发能力（Provider + Service + Tool），不进行业务编排。

---

## 一、Context

### 为什么做

Emily Core 目前缺少邮件收发能力。需求规格定义了以**无状态能力层**为核心设计的 Email 模块，让 SessionAgent 收发用户邮件（"帮我发邮件给XX"、"帮我查邮件"）。

### 设计要点

- **无状态**：模块不存储凭证、不维护连接、不持有会话。每次调用传入凭证
- **异步原生**：基于 `aiosmtplib` + `aioimaplib` 全链路 async
- **分层一致**：遵循项目现有 `Provider(ABC/impl) → Service(薄封装) → Config → Tool` 模式
- **失败即反馈**：不做内部重试，直接返回错误信息

### 本次不做

| 不做 | 原因 |
|------|------|
| ❌ 冷启动邮件报告 | 属于 ProjectAgent 业务编排，非模块能力 |
| ❌ Order 邮件轮询集成 | 属于 Scheduler 业务编排，后续单独实施 |
| ❌ Mock Provider | 模块聚焦真实实现，Mock 在业务方需要时再提供 |

### 3. SMTP Provider

**文件**：[emily-core/emily_core/providers/email/smtp_provider.py](emily-core/emily_core/providers/email/smtp_provider.py)（新增）

- 使用 `aiosmtplib.SMTP` 建连，支持 SSL（465 端口）/ STARTTLS（587 端口）
- 构造 MIME multipart 邮件（标准库 `email.mime`）：
  - 纯文本 → `MIMEText(text, 'plain', 'utf-8')`
  - HTML → `MIMEText(html, 'html', 'utf-8')`
  - 附件 → `MIMEBase` + base64 编码
- 错误分类映射：
  - `SMTPAuthenticationError` → `"AUTH_FAILED"`
  - `SMTPConnectError` / 超时 → `"CONNECTION_TIMEOUT"`
  - `SMTPResponseException` → 提取具体错误码
- 每次调用独立建连、发送、断开。不维护连接池
- 日志：`logger = logging.getLogger("emily.email.smtp")`
- `is_available()` — 三态缓存（`None`/`True`/`False`），检查凭证是否齐全

**参照**：[emily-core/emily_core/providers/rag/maxkb_provider.py](emily-core/emily_core/providers/rag/maxkb_provider.py) — provider 实现模式。

### 4. IMAP Provider

**文件**：[emily-core/emily_core/providers/email/imap_provider.py](emily-core/emily_core/providers/email/imap_provider.py)（新增）

- 使用 `aioimaplib.IMAP4_SSL` 建连（993 端口）
- `fetch_inbox()` 流程：
  1. `await imap.select('INBOX')`
  2. 构造 SEARCH 命令：`SEARCH SUBJECT "keyword" UNSEEN`（可选 FROM 过滤）
  3. `await imap.fetch(uid_set, '(RFC822 UID)')`
  4. `email.message_from_bytes()` 解析 MIME → 提取 From/To/Subject/Date/body_plain/body_html/attachments
  5. 设置 `Envelope.uid = imap_response_uid`
- `fetch_orders()`：等价于 `fetch_inbox(subject_filter="order", from_self=True, unread_only=True)` 并设 `is_order=True`
- `mark_read()`：`await imap.uid('STORE', uid_set, '+FLAGS', '\\Seen')`
- 日志：`logger = logging.getLogger("emily.email.imap")`

**aioimaplib 注意事项**：
- `search()` 返回逗号分隔的 UID 字符串（如 `b"1 2 3"`），需 `.split()` 解析
- `fetch()` 返回 `(result, [lines...])` 格式，每封邮件可能占多行
- 未找到邮件时返回空列表，不报异常

### 5. EmailService 薄封装

**文件**：[emily-core/emily_core/services/email_service.py](emily-core/emily_core/services/email_service.py)（新增）

完全按需求规格 §4.3 实现。薄封装层，组合 SMTP + IMAP Provider：

```python
class EmailService:
    """邮箱服务 —— 薄封装，不持有状态，不维护凭证，不启动后台任务。"""

    def __init__(self, smtp: SMTPEmailProvider, imap: IMAPEmailProvider):
        self._smtp = smtp
        self._imap = imap

    async def send(self, creds, to, subject, body, **kwargs) -> SendResult:
        return await self._smtp.send(creds, to, subject, body, **kwargs)

    async def fetch_inbox(self, creds, **kwargs) -> list[EmailEnvelope]:
        return await self._imap.fetch_inbox(creds, **kwargs)

    async def fetch_orders(self, creds, since_uid=None) -> list[EmailEnvelope]:
        return await self._imap.fetch_orders(creds, since_uid)

    async def mark_read(self, creds, uids) -> bool:
        return await self._imap.mark_read(creds, uids)
```

### 10. LLM Email Tools

**文件**：[emily-core/emily_core/tools/email_tool.py](emily-core/emily_core/tools/email_tool.py)（新增）

按需求规格 §6.2 实现两个 LLM 可调用的 Tool：

**`create_send_email_tool(email_service, config)` → `ToolDefinition`**：

| 属性 | 值 |
|------|-----|
| name | `send_email` |
| description | 发送邮件。需要调用者提供邮箱凭证。 |
| parameters | `to`(required/string), `subject`(required/string), `body`(required/string), `credential_source`(enum: user_memory\|env, default: env) |
| execute | async fn(args: dict) → dict |

handler 逻辑：
- `credential_source == "env"` → 从环境变量 `EMILY_EMAIL_IDKEY` / `EMILY_EMAIL_PASSWORD` 读取凭证
- `credential_source == "user_memory"` → TODO（依赖长期记忆系统，暂 fallback 到 env）
- 组装 `EmailCredentials`，调用 `email_service.send()`
- 返回 `{"success": true/false, "error": "...", "message_id": "..."}`

**`create_fetch_inbox_tool(email_service, config)` → `ToolDefinition`**：

| 属性 | 值 |
|------|-----|
| name | `fetch_inbox` |
| description | 检查邮箱收件箱，获取未读邮件列表。 |
| parameters | `credential_source`(enum, default: env), `limit`(int, default: 10) |
| execute | async fn(args: dict) → dict |

handler 逻辑：
- 从 env 或 user_memory 获取凭证
- 调用 `email_service.fetch_inbox()`，格式化结果
- 返回邮件列表的自然语言描述

**参照**：[emily-core/emily_core/tools/sm_tool.py](emily-core/emily_core/tools/sm_tool.py) — 完全相同的工厂函数 + ToolDefinition 模式。

def _init_email_module(self) -> None:
    """初始化邮箱模块：Provider + Service。fail-open，不阻塞 Core。"""
    try:
        from .providers.email import SMTPEmailProvider, IMAPEmailProvider
        from .services.email_service import EmailService

        smtp = SMTPEmailProvider()
        imap = IMAPEmailProvider()
        self._email_service = EmailService(smtp=smtp, imap=imap)

        logger.info("Email module initialized: SMTP + IMAP ready")
    except Exception as e:
        logger.warning("Email module init failed: %s", e)
        self._email_service = None

## 四、集成路径总览

```
bootstrap.init()
  → Config (email_* 字段就绪)
  → EmilyCore._ensure_initialized()
    → _init_email_module()
      → SMTPEmailProvider() + IMAPEmailProvider()
      → EmailService(smtp, imap)
      → self._email_service 存入 Core 实例
    → _build_session_pool()
      → SessionContext._email_service (via core=self)
        → create_all_tools(email_service=..., email_config=...)
          → ToolRegistry 注册 send_email + fetch_inbox
            → SessionAgent 用户说"帮我发邮件"
              → LLM chat_json → {tool: "send_email", params: {...}}
                → email_tool.handler(args)
                  → email_service.send(creds, ...) → SendResult
```

## 五、验证计划

### 单元级别
1. **SMTP Provider**：用真实 QQ 邮箱凭证发送一封测试邮件，验证 `SendResult.success == True`

1. **Config 加载**：`core_config.json` + 默认值正确映射到 `Config.email_*` 字段

3. **Tool 注册**：llm 可用时 `send_email` / `fetch_inbox` 出现在 ToolRegistry 列表中

### 端到端
1. **发送邮件**：通过 emy-test 发送"帮我发邮件给 xx@qq.com，主题：测试，正文：你好"，验证 LLM 路由到 `send_email` tool

3. **降级兜底**：未配置邮箱凭证时，Tool 不注册（不干扰其他功能）
