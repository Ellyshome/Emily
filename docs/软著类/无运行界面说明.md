# 无运行界面说明

软件名称：艾米地产项目人工智能调度管理软件
版本号：V1.0
著作权人：高海涛

一、运行形态
本软件为无图形用户界面（GUI）的计算机程序，以服务进程形式部署于服务器端常驻运行，
不提供面向用户的图形操作界面。

二、用户交互方式
用户通过即时通讯渠道（如QQ、企业微信自建应用等）以自然语言消息与本软件交互：
1. 用户发送消息（群聊@或私聊）后，软件经消息适配层完成协议转换与去重；
2. 会话调度器识别意图并拆解为任务执行单元，沿流水线执行；
3. 执行结果通过消息渠道异步回复用户。
此外，软件提供 REST API 接口，支持第三方系统集成调用。

三、补充说明
软件附带一个面向系统管理员的 Web 运维监控页面，仅用于展示运行状态
（会话、节点、文件、人员等监控信息），不承载任何业务操作功能，
不属于用户运行界面。

四、软件全称说明
鉴于本软件无运行界面，软件全称中类型词由"系统"调整为"软件"，
以正确体现软件类型。
