# 讲述过程：


## 概念讲述-它是什么
- 主旨：Emily是行业垂直领域，公司特化的AI智能体。讲解概念什么是行业垂直领域AI智能体
- 方式：
    - 从一个案例场景切入，讲解区别。如：去杭州东站接人，通过豆包询问列车出站口，豆包反馈无法获取，原因是，不同于进站口为固定公开信息，出站口是车站内部调度信息。由车站内部根据实际情况实时调整，非固定公开信息。通过站内指导，扫码微信小程序获取‘杭小东’入口，经过询问，它提供了准确实时的车次出站口与车次实时状态。
    - 现状对比：如果问豆包，大树移栽工艺方法，可以得到有效回复。新员工问蓝城乔木栽植验收标准。它肯定不知道。
    - 以此传达概念：通用人工智能与行业特化人工智能的区别：掌握内部信息

- 模拟场景案例展示：
    - 甲方视角：项目信息按主题查询、工程进展
    - 集团管理视角：项目状态、工程进展、主题穿透
    - 一线施工视角：工艺标准、验收标准
    - 一线管理视角：项目态势、项目日志、公司制度

## 解决痛点 - 它解决什么问题，提供什么价值

- 人员离职信息、经验流失 - 集团管理视角
