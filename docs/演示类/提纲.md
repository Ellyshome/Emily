## 反思 - 自然语言驱动复杂工具的意义 （引出 团队AI工具概念）
- 一方面 让个人能力有增幅；比如姚总使用AI做出了很多让人眼前一亮的东西。在AI时代之前，如果想做到类似程度，需要极大的精力去学习各种工具。认知负担很重。
- 另一方面，让更多的人，可以在更广的维度上协作。这个当前还不是很明显，我们举个例子。关于计算机操作，在图形化界面出现之前的DOS年代，人们只能通过命令行与计算机系统交互，这极大限制了计算机的使用参与人群，只有科学计算或自动化控制方向的人才会接触到它。而今天电脑，亦或其变种形态移动端的手机已经成了生活的一部分，再也离不开了。网购、打车、自媒体、办公协作。根源就在于，降低接入门槛，将更多的人拉入了互联网时代，哪怕只有小学文化，都可以纳入网络协作。

### 场景展示：一线员工自然语言交互引导信息录入
- 将更多人纳入到系统之下，降低认知负担。以下模拟黄湖项目展示自然语言沟通弱的一般劳动者使用场景。
    - Q：登记一下，铺装今天干了10平米
    - A：张师傅你好。10平米铺装已登记。根据你们班组当前执行的工作计划，是2#、4#楼间道路花岗岩铺装吗？
    - Q：对，就那儿
    - A：好，位置已确认：2#、4#楼间道路花岗岩铺装，工程量10平米。 请提供完工照片，要求：整体远景一张、局部近景一张，能清晰反映铺装完成面质量。
    - Q：（发送两张照片）
    - A：照片已收到并存档。本次登记信息如下，请确认：施工部位：2#、4#楼间道路花岗岩铺装。完成工程量：10㎡。影像资料：完工照片2张。另外提醒：该分项完工后，请及时联系景观班组负责人吴根林组织验收申报。
    - Q：好的知道了
    - A：收到。有其他进度随时报。

- 这段对话体现了什么
| 环节 | Emily 做了什么 | 背后的逻辑 |
| --- | --- | --- |
| 1 | 先接住模糊信息（"10平米"），不打断、不要求重报 | 降低录入门槛，让一线劳动者愿意用、敢用 |
| 2 | 结合该班组正在执行的**工作计划**，推断出施工部位并主动给出选项确认 | 系统里已有的信息主动调用，用户只需"是/否"，做选择比组织语言容易 |
| 3 | 依据节点成果要求，明确提出影像资料标准（远景+近景、反映完成面质量） | 把规范要求翻译成一线能听懂、可执行的动作，避免来回返工 |
| 4 | 登记完成后**复述全部信息**请用户确认 | 防止记错漏记，同时让用户心里有数 |
| 5 | 主动告知下一环节——联系景观班组负责人吴根林组织验收申报 | 流程要求无损直达一线，不用用户自己去翻制度 |

> 核心：不是让用户适应系统（"请按规范格式提交"），而是系统适应用户（"你怎么说都行，我帮你补全"）。对语言沟通弱的一线劳动者，能用大白话说明白的，就别让他填表。

# 备答
- emily是什么？企业外置大脑；AI 驱动的企业记忆中枢。
- emily的价值不在于将某项具体工作的效率提升多少或降低某项工艺的成本。在于将地产行业现有的管理，由高度依赖人为节点的模式，逐步过渡到以AI为中心的模式中。AI提供信息与参考，人负责决策和进化。
- 产生价值的方式是提高协作效率，提高信息利用率。资产数字化、活化。
- 当前市场情况。AI的应用，从计算机互联网内部开始，逐步向各行各业扩散。扩散速度以受众与行业特性有关。整体来说，受众面大，人机互动标准化程度高的产业，不依赖人实践最终成果的行业，AI化的速度快。地产类独立性强，依赖人做最终实现与协调管理的行业AI化慢。当前市场还没有对标项目。
- emily本质是记忆中枢，需要有足够的数据才能发挥价值。数据来自于项目沉淀的经验与经验应用的反馈迭代。

## 当前状态 与 进一步动作
- 软件已经闭环，可上线
- 依据的企业信息需要授权、清洗上线（当前装载了部分黄湖项目、萧山宁牧项目的经验资料。以及部分苏州项目资料）
- 当前信息沉淀路径：提交各类经验技术文本、制作全景节点（成果约束）、贡献信息标注（数据标注、清洗）

- 公司信息标注入网。如：蓝智讲堂，各项目复盘、竣工资料。

    - 框架运转磨合：全景节点的子节点分解、节点成果完工标准测试等。

## AI的能力边界与当前的行业状态：
- 有人用豆包指导去买榴莲，结果开出来的果肉达不到一般水准。不是AI做不了这个任务，而是挑榴莲这个专项任务没有专业技能训练。当前处于AI爆发起步阶段，优先蔓延到关联性强的数字领域（编程、文档处理），影响面大的领域（修图），而与自然关联强、依赖人实现的领域较慢。
