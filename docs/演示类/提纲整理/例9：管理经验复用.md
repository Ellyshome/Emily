# 例9：管理经验复用

- Q：关于景观装饰井盖。检查井是小市政班组做，装饰井盖是园林班组做。点位和高程的配合怎么控制？
- A：这个问题在'湖印晓庐'项目有过明确的配合经验，分高程控制和点位控制两方面说。高程上，两个班组进场前要先协商统一的井盖下浮尺度，具体数值根据装饰井盖的做法厚度计算，再额外预留2-3cm的排水找坡和施工误差余量。点位上，园林班组在道路场地放线时，小市政班组必须同步复核井位，对靠近道牙、转角等危险位置的井提前避让调整。湖印晓庐曾踩过坑：施工完成后才发现井位与道路边线冲突，最后靠斜砌井口勉强补救。提醒一下，斜砌这种补救做法能不能过验收，得看当地规范的要求，项目上尽量提前把点位核对清楚，别走到补救那一步。
