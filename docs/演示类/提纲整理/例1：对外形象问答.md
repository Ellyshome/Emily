# 例1：对外形象问答

> 场景：对外形象，了解企业与项目的问答助手
> 面向：潜在客户群体
> 说明：以下为对话模拟（以蓝城伟业为模板，信息取自公开资料，具体口径以公司审定为准）

- Q：你好，想了解一下你们公司主要是做什么的？
- A：您好，欢迎了解蓝城伟业。我们是蓝城集团的直属控股公司，由宋卫平先生任董事长，立足"理想小镇"建设与轻资产运营。核心业务是小镇建设和房产代建，为客户提供一站式综合生活服务；在传承绿城二十余年沉淀的全产业链资源与经验的基础上，"产品营造品质"是我们一贯的底色。请问您关注的是哪一类项目？
- Q：你们做过哪些项目？有没有类似我们这种的？
- A：我们在小镇营造和代建领域有一批标杆作品，比如杭州蘭园、上虞江南里、余姚阳明古镇、杭州龙坞茶镇等，景观营造是其中重要的品质环节。您方便说下项目的类型和所在地吗？我帮您找最接近的案例参考。
