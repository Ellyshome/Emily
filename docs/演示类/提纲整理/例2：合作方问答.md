# 例2：合作方问答

> 场景：对正在合作的甲方：提供项目观察窗口
> 面向：合作中的甲方
> 说明：以下为对话模拟（以蓝城伟业为模板，信息取自公开资料，具体口径以公司审定为准）

- Q（宁牧村委张海军）：本周我们村住宅项目的一期有什么进展？
- A：张书记您好，根据2023年9月12日最新的周工作汇总，宁牧项目一期目前处于大区施工阶段，整体完成度约85%。本周具体进展如下：建筑方面，12栋住宅楼主体结构已全部封顶，外墙真石漆完成92%，外窗安装完成88%，室内公区装修正在大面积推进；景观方面，大区硬质铺装完成72%，中心花园乔木种植基本完成，灌木及地被种植完成约65%，儿童活动区基础已浇筑完成；小市政排水方面，雨水主管道完成95%，污水主管道完成90%，化粪池及隔油池已安装到位，消防环路基层完成80%。整体进度符合计划节点要求。
- Q（宁牧村委张海军）：工地上有多少人在干活？
- A：张书记，根据现场登记打卡记录显示，目前一期现场共有11个班组在施工，总人数424人。其中总包单位4个班组共186人，包括土建班组82人、水电安装班组53人、精装修班组31人、安全及管理人员20人；各分包单位共7个班组238人，分别为外墙涂料班组38人、门窗安装班组29人、景观施工班组62人、市政排水班组34人、消防安装班组26人、智能化班组19人、电梯安装及其他配套班组30人。各班组流水作业，整体施工秩序正常。
