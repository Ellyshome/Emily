# 二十、我对这次拒稿的判断

我反而认为这次编辑意见**不是说你的技术内容不行**。

如果编辑认为论文没有创新、没有价值，通常会说：

> 缺乏创新性、理论基础不足、实验不足、研究价值有限……

> **“文章像报告，要围绕技术路线、实现方法、验证梳理。”**

> **他认为你写的是“做了什么”，但没有把它组织成“研究了什么技术问题、采用什么技术路线、怎么实现、如何证明”。**

而这恰恰是你这篇文章目前最好改的一类问题。
