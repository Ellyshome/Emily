# 重要概念：
## “以团队公共认知为基础、嵌入日常信息流、跨部门理解项目过程并实际办事”的垂直行业系统
## 垂直领域AI工具。不是“AI能不能回答问题”，而是“AI能不能进入一个组织，拥有持续的公共上下文，并在明确的权责边界内真正把事情办完”。


AI 技术深刻变革生产关系，但在地产行业中，其发挥效能的现状特征是"单人单功能"——通用 AI 工具以个人任务为中心，难以持续进入团队信息流。本文提出并实践了一套面向项目团队的完整框架，使 AI 服务面向团队而非个人。其基本方法是：抽离、梳理与整合地产团队的协作要素，将其映射为 AI 可理解的结构信息（全景节点图、SOP-Skill 等），并借鉴 AI-harness 工程中已成熟的多项实用技术，把团队协同模式映射为 AI 工程技术框架。该框架回答了一个行业命题：一个 AI 要在地产垂直领域真正运转并达到预期效果，至少需要具备哪些信息与机制。

# 研究问题（行业痛点）
- 项目记忆与过程经验,随人员流动而流失。
- 企业信息沉淀量巨大，精力有限难活化复用
- 传统数字化系统只擅长预设流程和结构化数据，对自然语言过程信息和非预设任务无力。培训成本高，跨企业难复用，无解释，可参与人少。
- 通用 AI 工具以个人单任务为中心，难以持续进入团队信息流并形成组织公共认知。
- 地产项目一线过程信息（现场/会议/IM 中的细节、试错经验、情境判断）不进入正式留档，造成「正式数据完整、过程认知分散」。 随人员流动而流失。
# 核心特性
- 有项目状态感知,团队工作过程记忆,企业管理架构,业务标准流作认知背景,服务行业团队为目标的harness系统
- 作为团队记忆中枢,全程陪跑项目做记录,不阻塞流程,以信管理团队认证过的信息为准


# 实现方法
- 全景图（重点）。将地产开发任务分解为独立的、有明确产出的子任务作为图的节点，以各节点的关联性作为边。引入‘以状态机’模式，提供项目态势感知、以节点独立性，提供资源访问权限隔离的参考。全景节点图，提供项目态势感知能力。提供图状相互关联互为输入条件-输出成果的关系图，通过图关联企业，通过企业关联人，实现鉴权、可见信息隔离。以全景节点作为项目级信息可见性与鉴权的基本组织单元。
    - 节点根据重要性有层级划分，从竣工验收这样的‘里程碑’节点，到X栋X层钢筋绑扎完成这样的小任务节点。
    - 节点可以由操盘单位管理
    - 节点参与者，可基于自身访问权限，给节点增加可见资源。
    - 节点成员访问资源权限，限于所参与的节点赋予的权限范围
    - 企业通过指定重要的全景节点的任务、时间、责任主体、节点成果考核标准，来管理项目进度与质量。
- 标准业务流（重点）。企业通过制定Sop流规范员工业务处理动作。系统管理员对sop业务流的认证负责。以 Skill 化 SOP 将业务流程封装为 Agent 可发现、可调用、可执行的能力单元。
- 核心任务编排规划框架（重点）：session、workitem执行引擎，三基本智能体分离任务组织、执行、核验任务。
- 鉴权系统。基于全景图节点的资源访问范围，与操盘管理单位的签证机制，节点管理员对节点负责，
- 通过上下文热更新实现团队记忆中枢。
- 以IM作为入口，实现‘直达一线的、自然语言交互的’、低门槛接入系统。基本0培训，不用下载熟悉新APP。推行学习成本低。
- IM工作群'卧底'+ 有记忆的任务执行工具 = 经验收集 - 入库 - 复用：新sop，新全景节点，定制生成机制。
- 上下文工程（Context Engineering）：信息聚合，渐进式发现的信息地图
