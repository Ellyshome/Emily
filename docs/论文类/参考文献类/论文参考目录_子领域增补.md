## 零、增补总览：对你论文最重要的三个发现

1. **Harness Engineering 是 2025-2026 年 Agent 领域的新学术话语体系**（Agent = Model + Harness），你的提纲里原本就用了"harness"一词（"session-agent 配置简单 harness"）——你的实践天然对接了这波学术框架。第 2 章引它，论文的理论档次直接提升，且"渐进式披露（Progressive Disclosure）"与你 P4 原则同名同义——你的原则有了国际文献背书。
2. **RAG 只是 Emily 的通用工具组件，不是核心特征**——论文中一笔带过（架构图标注 + 一句话），不设专节、不防御。RAG 子领域的摸排成果（R 组）仅作背景储备，第 2 章按需引用 1-2 篇即可。
3. **地产垂直 Agent 的学术研究集中在"咨询/投资/营销"**（PropGenie/HabitatAgent/ReCoQA/REITs），**工程管理侧的垂直 Agent 仍是空白**——这是你的精确 niche。

## 四、Harness Engineering 子领域 ★ 最重要的增补

### 核心概念

**Agent = Model + Harness**。Harness 指模型之外的一切系统组成：系统提示词、工具接口、编排逻辑、反馈循环、约束机制。2025-2026 年学术共识：**Agent 表现不佳的瓶颈往往不是模型，而是 Harness 设计**（同一模型仅改 Harness，编码基准可从 6.7% 跃至 68.3%）。

### 代表文献

| # | 题目 | 出处 | 要点 |
|---|------|------|------|
| H1 | Agent Harness Engineering: A Survey | CMU/Yale/JHU 等，arXiv 2025-2026 | ETCLOVG 七维度（执行/工具/上下文/生命周期/可观测性/验证/治理），映射 170+ 开源项目 |
| H2 | Meta-Harness: End-to-End Optimization of Model Harnesses | 斯坦福/MIT，2025 | Harness 作为可搜索优化的代码对象；上下文 token 降至 1/4 |
| H3 | Externalization in LLM Agents: A Unified Review | 2025-2026 | "外化"视角：记忆=时间外化、技能=程序性知识外化、协议=协作结构外化 |
| H4 | Harness Engineering as Categorical Architecture | 2025-2026 | 范畴论形式化：架构三元组 (G, Know, Φ) |
