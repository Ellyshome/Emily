# Emily 用户角色与权限矩阵

> 最后更新：2026-07-10 | 版本 v0.7.0

---

## 1. 权限层级说明

Emily 采用 6 级权限体系，从低到高：

| 级别 | 角色名称 | 说明 | 典型人员 |
|------|---------|------|---------|
| 0 | 访客 | 仅可查看公开信息 | 临时参访人员 |
| 1 | 参建执行 | 可记录和查看自己的工作内容 | 施工员、质检员、资料员 |
| 2 | 参建管理 | 可管理所在范围内的工作 | 项目经理、技术负责人 |
| 3 | 建设主管 | 可统筹项目全局 | 建设单位项目负责人 |
| 4 | 管理员 | 可管理用户和权限 | 系统管理员 |
| 5 | 系统管理员 | 最高权限，可修改系统配置 | 技术运维负责人 |

---

## 2. 各角色可用功能

| 功能 | 访客(0) | 参建执行(1) | 参建管理(2) | 建设主管(3) | 管理员(4) | 系统管理员(5) |
|------|---------|------------|------------|------------|----------|--------------|
| 查询事件/任务/会议 | 仅自己 | 自己+范围内 | 全部 | 全部 | 全部 | 全部 |
| 记录事件 | 否 | 是 | 是 | 是 | 是 | 是 |
| 记录会议 | 否 | 是 | 是 | 是 | 是 | 是 |
| 创建/管理任务 | 否 | 是（仅自己） | 是（团队） | 是（全部） | 是 | 是 |
| 归档文件 | 否 | 是 | 是 | 是 | 是 | 是 |
| 查询全量数据 | 否 | 否 | 是 | 是 | 是 | 是 |
| 管理项目节点 | 否 | 否 | 是 | 是 | 是 | 是 |
| 管理用户权限 | 否 | 否 | 否 | 否 | 是 | 是 |
| 修改系统配置 | 否 | 否 | 否 | 否 | 否 | 是 |
| 使用长期记忆 | 否 | 是 | 是 | 是 | 是 | 是 |

---

## 3. 企业类型与权限关系

Emily 支持按企业类型进一步细分权限范围：

| 企业类型 | 说明 | 权限特点 |
|---------|------|---------|
| 建设单位 | 项目业主方 | 默认建设主管(3)权限 |
| 施工单位 | 施工承包方 | 默认参建管理(2)权限 |
| 监理单位 | 第三方监理 | 默认参建管理(2)权限 |
| 设计单位 | 设计咨询方 | 默认参建执行(1)权限 |

---

## 4. 权限示例场景

### 场景一：施工员（参建执行）

- 可以记录自己负责区域的事件和任务
- 可以查看自己的历史记录
- **不能**查看其他施工队的记录
- **不能**删除或修改他人创建的内容

### 场景二：项目经理（参建管理）

- 可以查看本项目所有人员的记录
- 可以创建和分配任务给团队成员
- 可以管理项目节点和进度
- **不能**修改系统配置或管理其他用户的权限

### 场景三：建设单位负责人（建设主管）

- 可以查看所有参建单位的记录
- 可以审批关键节点
- **不能**直接管理用户账户

---

## 5. 权限申请流程

如果你的权限不足以完成某项操作，Emily 会提示你联系管理员提升权限。请向系统管理员说明：

1. 你的姓名和当前角色
2. 需要执行的操作
3. 业务原因

管理员审核后可在后台调整权限级别。
