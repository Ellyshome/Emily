### mitmproxy
- mitmweb UI : http://localhost:8081 ，密码 emily_proxy_2026
- 代理端口 : mitmproxy:8888 （容器间）
- 关闭代理 : 注释 docker-compose-napcat.yml 的 HTTPS_PROXY 和 SSL_CERT_FILE 两行 + docker compose restart emily-core
- 日志输出 : emily-data\logs\llm_trace.jsonl（机器读）+ llm_trace.md（人读）
通过mitmproxy Addon获取实时通讯流给AI工具

开关：environment:
  - LLM_TRACE_ENABLED=1           # 注释此行关闭落盘
- 开启 ：保留 LLM_TRACE_ENABLED=1 ，addon 在每个 DeepSeek API 响应到达时自动写 jsonl + md
- 关闭 ：注释该行（或设为 0 ），addon 不写任何数据，代理功能不受影响
- 无需重建镜像 ，改 docker-compose 后 docker compose up -d mitmproxy 即可
