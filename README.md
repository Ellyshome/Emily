# Emily - 地产开发团队公共大脑

> 陪跑地产开发全生命周期的AI工具，让个体经验沉淀为团队公共能力

---

## ✨ 项目简介

**Emily** 是 **团队公共大脑**，陪跑地产开发全生命周期的AI工具。

- **全面记录**：开发建设中的过程细节被完整记录，消除信息差
- **高效协作**：打破信息壁垒，大幅提升团队协作效率
- **知识沉淀**：行业经验不再随人走，永久沉淀为团队资产
- **模式升级**：信息管理告别"人盯人"的原始模式，AI工具融入地产行业日常
- **能力传承**：让个体经验沉淀为公共能力，每个人站在所有人的经验之上

Emily 采用 **三层 Agent 架构** 设计，结合 **细粒度权限控制** 和 **全局状态机驱动**，为项目各方提供精准、可控、可追溯的智能服务。

## 🎯 核心功能

### 🚀 **智能对话交互**
- ✅ **自然语言交互**：像聊天一样管理项目
- ✅ **多轮对话理解**：理解上下文，连续提问
- ✅ **消息双向归档**：入站/出站全记录，可追溯可审计
- ✅ **群聊 + 私聊**：支持群组协作和一对一咨询

### 📊 **全局状态机驱动**
- ✅ **节点级状态追踪**：90+ 标准节点，覆盖全流程
- ✅ **5 态节点流转**：未启动 → 进行中 → 阻塞 → 延期 → 完成
- ✅ **依赖关系管理**：自动校验前置条件，自动触发下游
- ✅ **里程碑看守**：到期自动预警，智能提醒相关方

### 🩺 **项目健康度监控**
- ✅ **卡滞节点自动巡检（5 分钟一次）
- ✅ **阻塞原因智能分析**，自动推荐解堵方案
- ✅ **健康指数量化评估**（0-100 分）
- ✅ **多维度风险预警**：进度/质量/安全/资源

### 🛠️ **丰富工具集**
- ✅ **任务管理**：创建/分配/追踪/验收
- ✅ **文档管理**：上传/下载/预览/版本控制
- ✅ **会议管理**：预约/纪要/待办/追踪
- ✅ **报表生成**：周报/月报/专项报告
- ✅ **照片上传**：施工记录自动关联任务

## 🚀 快速开始

### 环境要求

- Python 3.10+
- PostgreSQL 14+
- Docker & Docker Compose（推荐）

### Docker 部署

```bash
# 克隆项目
git clone <repository-url>
cd Emily

# 启动服务
docker-compose up -d

# 查看日志
docker-compose logs -f emily-core
```

### 本地开发

```bash
# 进入核心目录
cd emily-core

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，配置数据库和 LLM 参数

# 初始化数据库
python -m emily_core init

# 启动服务
python -m emily_core start
```
