# 大区景观工程 —— 标准节点说明

- 节点编号来源：`REF-CONST-LG-001`
- 节点名称：大区景观工程
- 节点类型：MILESTONE（工程阶段里程碑）
- 适用阶段：工程施工

## 一、节点分解

| 子项 | 说明 | 典型成果 |
| --- | --- | --- |
| 硬质铺装 | 园路、广场、台阶、道牙、井盖收口 | 铺装完成面、隐蔽验收记录、材料封样 |
| 绿化种植 | 乔木、灌木、地被、草坪 | 苗木进场验收、种植完成面、养护计划 |
| 景观水电 | 景观照明、水景、浇灌、排水 | 隐蔽验收、试运行记录、竣工图 |
| 验收 | 竣工验收、海绵验收、绿化验收 | 验收报告、整改闭环记录 |

## 二、参与方

- 建设单位：项目负责人 / 景观工程负责人
- 总包单位：项目经理 / 土建与安装接口人
- 监理单位：总监理工程师 / 专业监理工程师
- 景观工程分包：景观分包负责人 / 铺装、绿化、水电班组长

## 三、共享资料

- 景观施工图（含总图、详图、通用图）
- 小市政图（室外给水、排水）
- 海绵专项图纸
- 电气、弱电图纸
- 景观材料封样清单
- 景观条线工程管理手册

## 四、成果要求

按《景观条线工程管理手册》完成：

1. 竣工验收成果；
2. 海绵验收成果；
3. 绿化验收成果。

成果由专业负责人确认；AI 只做预审、归集和提醒，不替代人工签认。
