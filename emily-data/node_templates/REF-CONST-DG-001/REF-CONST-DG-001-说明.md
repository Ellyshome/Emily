## 节点说明

施工图设计完成是项目从设计阶段转入施工阶段的核心里程碑。此节点标志着各专业施工图纸已按国家标准深度完成绘制，并通过了施工图审查机构的技术审查，取得审查合格证。施工图是施工单位进行现场施工的法定依据，图纸必须审查合格方可用于施工。

**完成条件**：① 全套施工图设计文件已出图 + ② 施工图审查合格证已取得。两者缺一不可。

## 产物清单

### 全套施工图设计文件

**性质**：必需成果，目标 1 套。

**文件识别特征**（LLM 推理依据）：

全套施工图按专业分册组织，每个专业有独立图纸编号体系：

| 专业 | 图号前缀 | 典型内容 |
|---|---|---|
| 建筑（建施） | 建施-XX | 设计总说明、总平面图、各层平面图、立面图、剖面图、墙身/楼梯/卫生间详图 |
| 结构（结施） | 结施-XX | 结构设计说明、基础图、各层柱/墙/梁/板配筋图、楼梯结构图 |
| 给排水（水施） | 水施-XX | 给排水设计说明、各层给排水平面图、系统图、消防平面图 |
| 电气（电施） | 电施-XX | 电气设计说明、供配电系统图、各层照明/插座/弱电平面图、防雷接地、火灾报警 |
| 暖通（暖施） | 暖施-XX | 暖通设计说明、各层通风/空调/防排烟平面图、系统图 |

图纸通用特征：
- 每张图纸有标准图框，含工程名称、图纸名称、图号、比例、日期
- 图框内有设计单位名称和资质章（出图章）
- 审核版通常标注"送审图"或"审查版"
- 全套图纸数量：小型项目几十张，大型项目数百张
- 文件格式通常为 PDF（审图）或 DWG（源文件），常打包为 ZIP/RAR

**典型文件名**：含"施工图""建施""结施""水施""电施""暖施""送审图""蓝图"等关键词

### 施工图设计文件审查合格证

**性质**：必需成果，目标 1 份。

**文件识别特征**（LLM 推理依据）：

- 文件标题含"施工图设计文件审查合格证"或"施工图审查合格书"
- 合格证编号（如合字第 2025-XXX 号）
- 建设单位名称、项目名称、设计单位名称
- 审查机构名称及资质章
- 审查结论："审查通过"或"合格"
- 审查日期
- 审查专业清单（建筑/结构/给排水/电气/暖通）
- 审查机构公章
- 常附带：各专业审查意见汇总表及设计单位回复
- 文件通常为 PDF，1-10MB

**典型文件名**：含"审查合格证""施工图审查""审图合格""合字第"等关键词

### 评审通过文件（可选）

**性质**：非必需，内部质量控制凭证。

施工图正式送审前通常需通过甲方组织的内部评审或专家评审。包括：评审会议纪要（含专家签字和结论）、设计单位对评审意见的回复及修改说明、甲方审核确认单。与"审查合格证"的区别：评审是内部环节，审查是法定环节。

## 前置条件

- 建设工程规划许可证已取得
- 方案设计已获甲方批复
- 设计合同已签订（设计单位已确定）
- 勘察报告已完成

## 流程位置

规划设计阶段末期，设-计阶段的最后一个重大里程碑。完成后进入工程施工阶段。前序：规划许可证 → 方案设计 → 扩初设计。后续：施工许可证 → 施工单位定标 → 开工。
