## 节点说明

建设工程规划许可证是城市规划行政主管部门依法核发的行政许可文件，确认建设工程符合城市规划要求。这是项目从设计转入施工报建的关键前置条件——未取得此证不得办理施工许可证、不得开工。通常在方案设计通过规划审批后，由自然资源局（原规划局）核发。

**典型特征**：固定格式的证照文件，有明确的许可证编号、发证机关、发证日期。

## 产物清单

### 建设工程规划许可证（正本）

**性质**：必需成果，目标 1 份。

**文件识别特征**（LLM 推理依据）：

- 文件标题含"建设工程规划许可证"字样
- 证件编号格式：建字第 XXXXXX 号（如建字第 4403002025B0001 号）
- 发证机关：XX市自然资源和规划局（或自然资源局、行政审批局）
- 发证日期：XX年XX月XX日
- 建设单位名称及项目名称
- 建设位置、建设规模（建筑面积、层数等）
- 红色圆形公章（发证机关）
- 可能附带附件：单体明细表、规划总平面图（盖规划审批章）
- 文件通常为彩色扫描 PDF 或 JPG，1-5MB

**典型文件名**：含"规划许可证""建字第"等关键词

### 附件：单体明细表（可选）

规划许可证的附表，列出各建筑单体的栋号、使用性质、建筑面积、层数、高度等。

## 前置条件

- 设计方案已通过规划部门审批
- 建设用地规划许可证已取得
- 项目已取得立项批复

## 流程位置

规划设计阶段中后期。前序：方案设计审批 → 后续：建设工程施工许可证。
