# SOP-011-SYS — 全局状态机管理

| 字段 | 值 |
|------|-----|
| SOP 编号 | SOP-011-SYS |
| SOP 类型 | SYS（系统管理） |
| 版本 | v1.0 |
| 触发条件 | 管理员需要查看或操作项目节点状态 |
| 适用角色 | 系统管理员、项目经理 |
| 依赖工具 | REST API `state-machine` |

---

## §1 权限与适用场景

- **trigger_keywords**: 项目进度、节点状态、启动节点、完成节点、阻塞节点、延期节点、全局进度、审计日志、状态变更
- **allow_roles**: 系统管理员、项目经理、节点责任人
- **deny_conditions**: 无权限人员尝试修改节点状态
- **positive_examples**:
  - "查看项目整体进度" / "阶段三完成了多少" / "关键路径上哪个节点卡住了"
  - "标记节点 2.1.3 为已完成" / "1.1 节点阻塞了，原因是什么"
- **negative_examples**:
  - "帮我写个报告" / "今天的天气怎么样"（不属于状态机管理范畴）

---

## §2 意图定义

本 SOP 处理全局状态机的查询与操作请求，覆盖以下子意图：

| 子意图 | 说明 | 典型问法 |
|--------|------|----------|
| `query_node` | 查询单个节点详情 | "节点 5.1.3 什么状态" |
| `query_stage` | 查询阶段进度 | "阶段二的总体进度" |
| `query_overall` | 查询整体项目进度 | "项目整体完成了多少" |
| `query_satisfaction` | 查询节点前置满足度 | "节点 2.1.5 的前置条件满足了吗" |
| `change_status` | 变更节点状态 | "标记 1.1 为已完成" |
| `force_activate` | 强制激活外部触发节点 | "变更令下发，启动 5.12.5" |
| `query_audit` | 查询审计日志 | "最近的状态变更记录" |

---

## §3 执行流程

### §3.1 查询类

1. 识别查询目标（节点ID / 阶段编号 / 全局）
2. 调用对应 API：
   - `GET /api/v1/state-machine/nodes/{node_id}` — 节点详情
   - `GET /api/v1/state-machine/stages/{stage_id}/progress` — 阶段进度
   - `GET /api/v1/state-machine/progress` — 整体进度
   - `GET /api/v1/state-machine/nodes/{node_id}/satisfaction` — 前置满足度
3. 格式化回复：节点名称 + 当前状态 + 完成百分比 + 关键前置依赖

### §3.2 状态变更类

1. 识别目标节点和期望状态
2. 校验操作权限（责任人 / 管理员）
3. 调用 `PUT /api/v1/state-machine/nodes/{node_id}/status`
4. 系统自动校验状态转移合法性（NOT_STARTED→IN_PROGRESS→COMPLETED 等）
5. 自动写入审计日志 + 级联更新下游满足度
6. 返回变更结果（含级联影响的节点列表）

### §3.3 节点状态转移规则

```
未启动 → 进行中 → 已完成
              → 已阻塞 → 进行中
                       → 已延期
              → 已延期 → 进行中
                       → 已完成
已完成 = 终态，禁止一切转移
```

> 关闭进度项以同步下游节点为业务行为依托数据库业务逻辑进行异步状态机的后续作业触发，不受限于本SOP的同步完成性

---

## §4 输出规范

- 查询结果应包含：节点编号、节点名称、当前状态（中文）、完成百分比、所属阶段
- 阶段进度：`阶段N（名称）：X/Y 已完成（Z%）`
- 整体进度：`项目整体进度：X/Y 节点已完成（Z%），分布在 N 个阶段`
- 状态变更确认："节点 {node_id}「{name}」已从 {from} 变更为 {to}"，级联影响的节点予以列出

---

## §5 故障处理

| 故障场景 | 处理方式 |
|----------|----------|
| 节点不存在 | 返回 404，提示检查节点编号 |
| 非法状态转移 | 返回 400，提示当前状态和允许的目标状态 |
| 模块未初始化 | 返回 503，提示状态机模块未启用 |
| 级联更新超时 | 返回部分成功，标注级联未完成的节点 |
