# 苗木使用方案审核任务手册

> 适用专家编号：EXP-001 | 任务类型：设计阶段方案评审 | 审核对象：植物设计说明 + 植物配置表

---

## 一、审核任务说明

本任务要求对提交的园林景观工程"植物设计说明"及"植物配置表"进行全面审核，对照《园林景观苗木使用审核职能手册》中的量化标准，逐项检查并提出评审意见。

## 二、审核维度与权重

| 维度 | 权重 | 满分 | 审核要点 |
|------|------|------|---------|
| 乔木密度合规 | 20% | 20 | 各区域百平米密度是否在标准区间内 |
| 草灌面积比 | 15% | 15 | 各绿地类型草灌比是否合规 |
| 换土与种植穴 | 15% | 15 | 换土深度/直径是否满足标准 |
| 土壤理化参数 | 15% | 15 | 是否包含理化参数要求且数值达标 |
| 种植间距 | 15% | 15 | 株行距是否满足最小间距标准 |
| 苗木规格 | 10% | 10 | 进场规格是否达到最低要求 |
| 成活率保证 | 5% | 5 | 是否包含成活率保证条款 |
| 生物多样性 | 5% | 5 | 品种数、单一树种占比是否达标 |

**总满分：100 分**

## 三、评审结果分级

| 等级 | 分数区间 | 处理方式 |
|------|---------|---------|
| 通过 | ≥85 分 | 可直接进入施工图阶段 |
| 修改后通过 | 70-84 分 | 退回修改，修改后复核 |
| 重做 | <70 分 | 方案不达标，需重新设计 |

## 四、输出格式要求

评审输出必须为以下 JSON 格式：

```json
{
  "status": "success|partial|failed",
  "score": 0,
  "score_dimensions": {
    "乔木密度合规": 0,
    "草灌面积比": 0,
    "换土与种植穴": 0,
    "土壤理化参数": 0,
    "种植间距": 0,
    "苗木规格": 0,
    "成活率保证": 0,
    "生物多样性": 0
  },
  "issues": [
    {
      "location": "具体位置（如某区域/某植物表行号/某章节）",
      "standard": "依据的审核标准原文",
      "severity": "高|中|低",
      "description": "问题描述"
    }
  ],
  "conclusion": "总体评审结论",
  "recommendation": "通过|退回修改|重做"
}
```

## 五、特别注意

- 审核时必须**逐项对照职能手册的量化标准**，不得凭经验判断
- 土壤理化参数缺失直接扣满该项 15 分
- 成活率保证条款缺失直接扣满该项 5 分
- 任何单项得分为 0 的，总评等级不得高于"修改后通过"
- 存在高严重度问题的，总评等级强制为"重做"
