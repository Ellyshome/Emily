# 景观装饰井盖 · 点位与高程配合经验

- 项目/专业：湖印晓庐 / 景观工程
- 关键词：装饰井盖、检查井、点位控制、高程控制、井盖下浮、2-3cm、斜砌、小市政班组、园林班组
- 适用问题：检查井由小市政班组施工、装饰井盖由园林班组施工时，点位和高程怎么配合控制？

## 一句话结论

检查井由小市政班组做、装饰井盖由园林班组做，配合控制分“高程”和“点位”两条线：进场前统一井盖下浮尺度，放线时小市政同步复核井位；湖印晓庐曾因井位与道路边线冲突，最后靠斜砌井口补救，应尽量提前核对，避免走到补救那一步。

## 高程控制

- 两个班组进场前先协商统一的井盖下浮尺度。
- 下浮数值按装饰井盖的做法厚度计算，再额外预留 2–3cm，用于排水找坡和施工误差余量。
- 井筒收口标高 = 完成面标高 − 装饰井盖厚度（含盖板及铺装/绿化基层）。
- 小市政移交前应实测每个井的井座标高，形成实测数据交给园林复核。

## 点位控制

- 园林班组在道路场地放线时，小市政班组必须同步复核井位。
- 对靠近道牙、转角等危险位置的井，提前避让调整。
- 不要等施工完成后再发现井位与道路边线冲突。
- 建议把市政井位图与景观铺装总平面图叠加会审，逐井核对。

## 踩坑记录

- 湖印晓庐项目施工完成后才发现井位与道路边线冲突，最后靠斜砌井口勉强补救。
- 斜砌这种补救做法能否通过验收，要看当地规范要求；项目上应尽量提前把点位核对清楚，不要依赖补救。
