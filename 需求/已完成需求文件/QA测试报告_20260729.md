## 五、发现的问题

### BUG-01: events 表 project_id 外键约束

- **严重级别**: P2（功能正常但录入失败）
- **现象**: `INSERT INTO events ... project_id=翠湖庭院 → ForeignKeyViolation`
- **原因**: LLM 将项目名"翠湖庭院"作为 project_id 而不是查 projects 表取 UUID
- **影响**: 事件录入功能不可用（预存 bug，非本次改动引入）
- **建议**: 在事件录入 handler 中增加 project_id 解析步骤：按项目名查 projects 表 → 取 id

### BUG-02: planner prompt 文件缺失

- **严重级别**: P3（不影响功能，有硬编码兜底）
- **现象**: `Prompt 'planner' file not found, using hardcoded default`
- **影响**: 修改 `prompts/planner.md` 不会生效，使用 `prompt_loader.py` 中的硬编码值
- **建议**: 创建 `emily-data/prompts/planner.md` 或移除文件查找路径

### CONSTRAINT: WAITING_FOR_INPUT 流程无法端到端触发

- **说明**: node3 的 `needs_input` 检测依赖工具 handler 返回 `{"needs_input": True, "question": "..."}`，当前无工具实现此返回格式
- **验证手段**: 已通过单测验证代码路径（状态机转换、scheduler 分支、SessionAgent fork），端到端需等工具适配后补充
- **建议**: 后续为人员指派、日期确认等工具添加 needs_input 返回
