## 四、缺陷与偏差

### D1（🔴 高，硬验收失败）：世界书态势的时间线/事件段落未按可见节点过滤

- **现象**：`render_brief` 的「🔴 逾期」行、`render_full` 的「【近期事件】」「【7天内到期】」「【阻塞】」段直接取用 `temporal` / `relation` 字段，**未与 `authorized_node_ids` 求交**。
- **证据**：U-L1（`authorized_node_ids=[]`）摘要与 world 全文中出现未授权节点名 `方案设计 / 可行性研究 / 规划许可证办理`。
- **影响**：违反 AC-US-01.2 / AC-US-04.2 的"零越权泄漏"；推送至路由 prompt 与查阅结果，低权限用户可获知未授权节点信息。
- **定位**：[fetch_world_book.py](file:///d:/app/Emily/emily-core/emily_core/session/fetchers/fetch_world_book.py) `render_brief`（逾期行）与 `render_full`（temporal/relation 段）。DD-M1a 的示例代码即如此，DD 自检 A2 使用无 `temporal` 键的合成数据，故未暴露；真实数据下必现。

### D2（🟡 低，鲁棒性观察）：`render_brief/render_full` 对未归一化 sections/输入默认 fail-closed

- `render_full(secs, level)` 若收到**未经 `parse_sections` 归一**的章节（缺 `levels` 键），该章节被静默丢弃（`level not in []`）。生产路径（`SessionDataFetcher` / `meta_cognition_tool`）均先 `parse_sections`，故不影响；验收计划 TC21 的字面片段直接传裸 dict，会呈现"未标注条文不可见"。建议在渲染层也补默认级别，彻底落实约束 #8。

### D3（ℹ️ 说明，非新增）：运行时 ERROR 溯源

- 窗口内 2 处 ERROR：① `emily.llm: Failed to parse LLM response as JSON`（模型侧偶发，既有）；② `emily.langgraph.loop: tool_node query_my_nodes failed: UnboundLocalError 'nid'`——位于 **未改动** 的 `tools/node_task_tool.py`，属既有缺陷，非本次改动引入。建议另立缺陷单。

### D4（ℹ️ 执行偏差，已获证据）：TC04 采用安全变体

- 计划原文「…然后给每个负责人发提醒」会向**真实用户**（李景利/黄志强等）群发提醒。为免打扰真实人员，改用等价「先查逾期节点 → 然后记一条事件」变体，仍完整覆盖"依赖序：先查后办"；并追加机制单测证明 `WI-2.depends_on=[WI-1]`。

### D5（ℹ️ 未能测量）：TC25.2 响应时间劣化

- 无"改造前"基线，无法计算 ≤20% 偏差；仅以"零额外规划 LLM 调用"（TC25.1）间接佐证。
