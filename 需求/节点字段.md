# 数据库字段列表（2026-07-27 更新）

## project\_nodes（节点主表）

### 必填业务字段

| 字段                   | 类型           | 说明                                                   |
| -------------------- | ------------ | ---------------------------------------------------- |
| `project_id`         | VARCHAR(100) | 项目归属，FK→projects.id                                  |
| `node_id`            | VARCHAR(100) | 节点编号（业务主键），例：SG-JG-01-2026                           |
| `node_name`          | VARCHAR(500) | 节点名称                                                 |
| `owner_dept_id`      | VARCHAR(100) | 主责条线，FK→company\_info.id                             |
| `related_company_id` | VARCHAR(100) | 关联单位（DB留存列，API已退休；由 node\_participant\_companies 推导） |
| `deadline`           | VARCHAR(50)  | 截止时间（ISO8601）                                        |

### 选填业务字段

| 字段               | 类型           | 默认值      | 说明                                  |
| ---------------- | ------------ | -------- | ----------------------------------- |
| `land_parcel_id` | VARCHAR(100) | ""       | 关联地块ID                              |
| `remark`         | TEXT         | ""       | 备注                                  |
| `parent_node_id` | VARCHAR(100) | ""       | 父节点ID（自引用，嵌套上限3层）                   |
| `stage_id`       | INTEGER      | 0        | 所属阶段ID，对齐 projects.lifecycle\_stage |
| `child_weight`   | VARCHAR      | "1.0000" | 在父节点中的权重（DECIMAL 5,4）               |
| `startup_doc_id` | VARCHAR(100) | ""       | 启动文档记录ID，FK→files.id                |

### 系统字段

| 字段                    | 类型           | 默认值              | 说明                                                               |
| --------------------- | ------------ | ---------------- | ---------------------------------------------------------------- |
| `id`                  | VARCHAR      | UUID             | 主键                                                               |
| `creator_id`          | VARCHAR(100) | 必填               | 录入人ID                                                            |
| `created_at`          | VARCHAR(50)  | 必填               | 录入时间（ISO8601）                                                    |
| `approver_id`         | VARCHAR(100) | ""               | 批准人ID                                                            |
| `approved_at`         | VARCHAR(50)  | ""               | 批准时间                                                             |
| `completed_at`        | VARCHAR(50)  | ""               | 完成时间                                                             |
| `is_discarded`        | BOOLEAN      | FALSE            | 是否废弃                                                             |
| `progress`            | VARCHAR      | "0.00"           | 整体进度（0.00-100.00）                                                |
| `status`              | VARCHAR(20)  | "NOT\_ACTIVATED" | NOT\_ACTIVATED / CONDITIONS\_NOT\_MET / IN\_PROGRESS / COMPLETED |
| `progress`            | INTEGER      | 0                | 排序序号                                                             |
| `responsible_user_id` | VARCHAR(100) | ""               | 责任人，FK→users.id                                                  |
| `node_type`           | VARCHAR(20)  | "WORK\_PACKAGE"  | MILESTONE / WORK\_PACKAGE / TASK                                 |
| `visibility_mode`     | VARCHAR(30)  | "specific"       | specific（按绑定）/ all\_project\_files（全项目文件可见）                      |
| `updated_at`          | VARCHAR(50)  | 必填               | 最后更新时间（ISO8601）                                                  |

## node\_participant\_companies（节点-参与单位 M:N）★新增

| 字段           | 类型           | 说明                              |
| ------------ | ------------ | ------------------------------- |
| `node_id`    | VARCHAR(100) | 节点ID，FK→project\_nodes.node\_id |
| `company_id` | VARCHAR(100) | 参与单位ID，FK→company\_info.id      |
| `added_by`   | VARCHAR(100) | 添加人ID                           |
| `added_at`   | VARCHAR(50)  | 添加时间                            |
| 唯一约束         | <br />       | (node\_id, company\_id)         |

> 参与单位通过此表以多对多方式关联。`related_company_id` 由系统自动从参与单位列表中推导（优先管理单位，其次首项）。

## node\_participants（节点-参与人 M:N）

| 字段                 | 类型           | 说明                                |
| ------------------ | ------------ | --------------------------------- |
| `node_id`          | VARCHAR(100) | 节点ID，FK→project\_nodes.node\_id   |
| `user_id`          | VARCHAR(100) | 参与人ID，FK→users.id                 |
| `participant_role` | VARCHAR(20)  | participant / approver / observer |
| `added_by`         | VARCHAR(100) | 添加人ID                             |
| `added_at`         | VARCHAR(50)  | 添加时间                              |
| 唯一约束               | <br />       | (node\_id, user\_id)              |

## node\_deliverables（产出成果）

| 字段                 | 类型           | 说明                              |
| ------------------ | ------------ | ------------------------------- |
| `deliverable_id`   | VARCHAR(100) | 成果编号（业务主键）                      |
| `node_id`          | VARCHAR(100) | 所属节点，FK→project\_nodes.node\_id |
| `deliverable_name` | VARCHAR(500) | 成果名称                            |
| `target_amount`    | VARCHAR      | 目标量（DECIMAL）                    |
| `current_amount`   | VARCHAR      | 当前量（DECIMAL）                    |
| `is_required`      | BOOLEAN      | 是否必需成果                          |
| `created_at`       | VARCHAR(50)  | 创建时间                            |

## node\_dependencies（前置依赖）

| 字段                          | 类型           | 说明                                            |
| --------------------------- | ------------ | --------------------------------------------- |
| `node_id`                   | VARCHAR(100) | 下游节点，FK→project\_nodes.node\_id               |
| `depends_on_deliverable_id` | VARCHAR(100) | 依赖的成果ID，FK→node\_deliverables.deliverable\_id |
| `depends_on_node_id`        | VARCHAR(100) | 上游节点ID（冗余），FK→project\_nodes.node\_id         |
| `dependency_type`           | VARCHAR(20)  | DELIVERABLE / TIME                            |
| `weight`                    | VARCHAR      | 权重（0.0000-1.0000，≥999 视为阻塞依赖）                 |
| 唯一约束                        | <br />       | (node\_id, depends\_on\_deliverable\_id)      |

## node\_accessible\_files（节点可见文件 M:N）

| 字段         | 类型           | 说明                              |
| ---------- | ------------ | ------------------------------- |
| `node_id`  | VARCHAR(100) | 节点ID，FK→project\_nodes.node\_id |
| `file_id`  | VARCHAR(100) | 文件ID，FK→files.id                |
| `added_by` | VARCHAR(100) | 授权人ID                           |
| `added_at` | VARCHAR(50)  | 授权时间                            |
| 唯一约束       | <br />       | (node\_id, file\_id)            |
