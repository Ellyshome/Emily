# 如‘景观工程施工图苗木应用审核’专家（这个Agent载入公司对景观施工图苗木设计说明与表的审核标准、关注点、打分规则等，对其量化打分）

- 在workitem中，增加一个可选节点：专家评审
- 建立一个专家库，每个专家负责一项具体的业务。
- 建立一个SOP，被标记为admin的单位员工，可新建专家进入专家库（需要项目管理员确认后方可生效），
- 新建专家必备信息，专家名称，专家一句话职能描述。职能手册。
- 专家Agent创建时，需要载入的内容：
    - 全量载入职能手册内容。
    - 任务手册
    - 要求被处理的文件
- 专家Agent返回成果：根据审核要求的评审成果。
