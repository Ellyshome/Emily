# 位图识别技能

## 功能特点
- 使用硅基流动的先进 AI 模型进行文字识别
- 支持并发处理多张图片
- 高准确率的文字识别和排版
- 支持多种图片格式（JPG、PNG、BMP 等）
- **输出 Markdown 格式**：保留标题层级、表格、加粗等结构
- 自动识别并标注页码信息（格式：`[页码：X]`）
- **并发识别，完成后统一按页码升序排序输出**；无页码图片追加在末尾，保持原始输入顺序
- 每条结果同时记录原始文件名与识别出的页码，便于溯源
- **支持将识别结果保存为指定格式的文件**

## 使用场景
- 识别教科书、文档等印刷材料
- 批量处理大量图片文件，结果按页码自动排序
- 提取图片中的文字内容（含表格）
- **将 OCR 识别结果保存为 md、txt 等格式的文本文件**

## 技术优势
- 基于硅基流动的先进 AI 模型（`Qwen/Qwen3-VL-8B-Instruct`，在 `config.json` 中配置）
- 支持复杂背景和排版的识别
- 输出 Markdown 格式，完整保留表格、标题、列表层级
- 并发处理提高效率，完成后统一按页码排序
- 每张图结果保存原始文件路径与页码，便于多图溯源
- **智能文件命名：跳过页码标注，根据正文内容自动生成文件名**

## 输入参数
- `image_paths`: 一个或多个图片文件路径
- `extension`: （可选）输出文件的扩展名，如 `txt`、`md` 等

## 输出
- 识别结果以 Markdown 格式呈现，保留原文结构（标题、表格、列表等）
- 每条结果标注原始文件名和识别出的页码
- 并发识别完成后，统一按页码升序排序输出
- **（可选）保存的文本文件，文件名根据正文内容自动生成（跳过页码标注部分）**

## 使用方法

### 基本用法（仅显示识别结果）

```bash
# 处理单张图片
python main.py target.jpg

# 处理多张图片（并发识别，结果按页码排序输出）
python main.py img1.jpg img2.jpg img3.png
```

### 高级用法（保存为文件）

```bash
# 保存为 txt 文件
python main.py img1.jpg img2.jpg txt

# 保存为 md 文件
python main.py img1.jpg img2.jpg img3.png md

# 保存到与图片相同的目录
python main.py D:/photos/page1.jpg D:/photos/page2.jpg md
```

**说明：**
- 当最后一个参数为扩展名时，识别结果会自动保存到**与图片相同的目录**中
- 文件名跳过开头的 `[页码：X]` 标注，从正文内容前 30 个字符生成
- 自动移除文件名中的非法字符（`<>:"/\|?*`）
- 支持的扩展名可以是 `txt`、`md`、`json` 等任何文本格式

## 配置选项
- 识别语言：支持中英文等多种语言
- 输出编码：UTF-8
- API 配置：在 `config.json` 中设置 API 密钥、API URL 和模型
- 模型：`Qwen/Qwen3-VL-8B-Instruct`（在 `config.json` 中配置）
- 并发数：默认 6 个线程

## 注意事项
- 需要有效的硅基流动 API 密钥
- 图片大小建议不超过 10MB
- 网络连接需要稳定
- 并发处理可能会增加 API 调用频率，请确保不超过 API 限制
- **文件名会根据正文内容自动生成，如果内容过长会被截断至 30 个字符**
- **保存的文件与图片在同一目录中**
