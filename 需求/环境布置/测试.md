## 1. 数据库清理与重置

**推荐方案：全量重置**

```powershell
# 1. 停服并清除数据卷
docker compose -f docker-compose-napcat.yml down -v

# 2. 重启（PostgreSQL 自动创建 emily 库，emily-core bootstrap 自动建表）
docker compose -f docker-compose-napcat.yml up -d
```

Emily 使用 `Base.metadata.create_all()` 自动建表，重启 emily-core 即恢复完整 schema。种子数据脚本可重复执行。无线上业务数据，`-v` 清数据卷无风险。

按 FK 依赖逆序清空的 SQL 脚本见：[000_reset_all.sql](../../emily-core/emily_core/infrastructure/database/scripts/000_reset_all.sql)
