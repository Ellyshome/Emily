### Issue 2: 用户 IM 绑定需要对齐
**状态**: 待修复
**说明**: 测试用户 ID 与 user_im_bindings 表的 im_user_id 需保持一致，否则每次会创建新用户。

### Issue 3: 状态机工具调用验证
**状态**: 待验证
**说明**: 需要检查 query_sm_status 和 try_match_and_complete 是否被正确调用。
