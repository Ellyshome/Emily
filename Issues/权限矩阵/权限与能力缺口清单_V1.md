## 一、判定口径：IM 侧"可达"的四条通路

| # | 通路 | 事实源 | 说明 |
|---|------|--------|------|
| P1 | 级别层 | `ToolRegistryRepo.get_available(level)` | `base`=全员；`business`：`all` 全员 / `write_l2` L2+ / `write` L3+ / `admin` L5+；`project`=L5+ |
| P2 | SOP 声明层 | SOP 文档 §3.2 表格 → `SkillDoc.tools` → `fetch_available_tools._merge_sop_declared_tools` | 只做**并集放行**；用户持有该 SOP（`sop_allow`）时其声明工具一并可见 |
| P3 | 自由工具集 + 写护栏 | `session/capability_catalog.py` | 高危写语义（`overwrite`/`delete`）不进自由工具集；非 `read` 写能力须在档位白名单内（`FallbackPolicy.resolve`） |
| P4 | 兜底白名单 | `fallback_policy.py`（basic/advanced）+ SOP-999 派生白名单（`exposure_mode=sop_only` 排除） | 兜底/直调路径的唯一事实源 |

**判定**：存在 P1–P4 任一合法通路 = IM 可达；四条都不通 = IM 不可达（"仅后台"）。
**注意**：P3 的写护栏依赖 `BusinessFlowTool.write_mode` 标注，标注缺失即护栏失效（见 G-9）。

## 三、emy-console 功能 ↔ IM 等价性对照

定位依据：`.trae/skills/_shared/constitution.md` C13"Web 控制台 = 观察窗口（不得自造功能）"，以及本次约定"console 有的**基本功能**，原则上都能经 IM 实现"。

### 3.1 业务写操作（**必须**有 IM 等价通路）

| console 端点 | 功能 | IM 等价通路 | 判定 |
|---|---|---|---|
| `POST /upload` | 上传归档 | `record_file`（SOP-004，L2+） | ✅ 有（但见 G-11：两者不同源） |
| `POST /file-delete` | 软删除文件 | `delete_file` | ⚠️ 工具在，但无 SOP 承载（G-8）、校验过宽（G-12） |
| `POST /file-confidentiality` | 密级调整 | 无 | ❌ **违反**（G-4） |
| `POST /rag-index` | RAG 入库 | `embed_and_index`（L3+） | ⚠️ 工具在，但无 SOP 声明 |
| `POST /rag-delete` | RAG 出库 | 无 | ❌ **违反**（G-5） |
| `POST /node-participant` | 节点参与单位维护 | 无 | ❌ **违反**（G-6） |
| `POST /node-file` | 节点共享文件增删 | 仅间接（成果/进度带文件） | ❌ **违反**（G-7） |
| `POST /chat/send`、`POST /chat/upload` | 消息模拟器 | —— | ⏭ 豁免：本身就是"模拟 IM"，是 IM 通道的观测入口，非业务功能 |

### 3.2 只读观测（豁免，不要求 IM 等价）

`/users`、`/resources`、`/node-table`、`/files`、`/project-events`、`/rag-search`、`/rag/backends`、`/prompts`、`/prompt`、`/langgraph-tools`、`/logs`、`/llm-trace`、`/self-check`、`/session-archives`、`/test-cases`、`/channels`

> 其中 `/users`、`/resources`、`/node-table`、`/files`、`/project-events`、`/rag-search` 在 IM 侧已有等价查询能力（`query_data` / `query_files` / `query_node` / `query_my_nodes` / `knowledge_search` / `meta_cognition_read`）；其余为**系统观测面**（日志、trace、自检、测试用例、模板），设计上属运维后台，不要求 IM 等价。

### 3.3 配置类写操作（豁免，但需留痕）

`/mcp/server`、`/mcp/toggle`、`/mcp/probe`、`/test-settings`、`/channels/wxmp-domain`、`/channels/wecom-params`

> 属"系统配置/接入参数"，非业务基本功能 → 豁免；但 `Issues/操作留痕治理_需求基线_V1.md` 要求这类写操作补业务事件留痕。

### 3.4 违反项汇总（需你确认处理方式）

1. **密级调整** —— IM 无入口（G-4）
2. **RAG 出库** —— IM 无入口，且 console 路径无等级判定（G-5）
3. **节点参与单位维护** —— IM 无入口（G-6）
4. **节点共享文件关联** —— IM 无直接入口（G-7）
