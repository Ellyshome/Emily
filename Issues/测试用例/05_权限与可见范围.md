# 05 权限与可见范围

> **本类目标**：验证等级权限、项目归属推导、行级过滤、能力可见集 fail-closed、门禁单一判定点，以及权限矩阵接口。
> **用例数**：13　|　**编号前缀**：`FR-G*`、`FR-P*`
> **执行通道**：A（对话模拟）+ E（库核对）+ B（接口）
> **来源**：`LangGraph编排内核化_功能复现测试用例_V1.md` G 组；`LangGraph编排内核化_功能复现测试报告_V1.md` 第七节补测

## 前置

1. **真实用户**，覆盖 3 个对照面：L1 访客 / L3~L4 参建执行与管理 / L6 系统管理员。
2. 掌握对照项目：用户**参与**的项目 vs **非参与**的项目（如「星河湾」为典型非参与项目）。
3. 权限等级以**代码为准**：`emily_core/permission/level.py`（L1 访客 … L6 系统管理员）；`is_admin(level)=level>=5`，`is_sys_admin(level)=level>=6`。

## 关键对照矩阵（执行时按此设计对照）

| 用户 | 等级 | 公开(0) | 内部(1) | 机密(2) | 说明 |
|------|------|--------|--------|--------|------|
| 访客/供应商 | L1 | **全员可见（不走节点判定）** | ✗ | ✗ | 公开文件全员可见；内部/机密一律不可见 |
| 参建执行 | L2 | 参与节点 | 参与节点 | ✗ | |
| 参建管理 | L3 | 参与节点 | 参与节点 | ✗（除自传/显式授权） | |
| 建设主管 | L4 | 参与节点 | 参与节点 | ✗（除自传/显式授权） | |
| 管理员 | L5 | 全局 | 全局 | ✗（除自传/显式授权） | L5 改密级为机密后**自己也不可见**（已确认可接受） |
| 系统管理员 | L6 | 全局 | 全局 | **全局原生可见** | 白名单之外的管理员通道 |

## 备注

- `FR-G6`（行级过滤 fail-open）与 `FR-G8`（编号口径差）**不是缺陷**，但分别为**待收窄点**与**文档口径差**；修复或统一后须复测。
- 权限类用例**必须先确认真实 UUID**（伪造会导致降级到访客路径，测出的"被拒绝"是假阳性）。
- **FR-G9 为固定项**：以后每次回归「文件可见范围」都必须带访客锚点——固定以「周访客」（无公司、L1，由 `014_seed_rag_visitor.sql` 注入，UUID 动态生成、按 username 解析）的 ID 校验：可见集 == 全部公开文件，且内部(1)/机密(2) 零泄露。对应可执行断言为 `rag_test_harness.py` 的 TC-03。
