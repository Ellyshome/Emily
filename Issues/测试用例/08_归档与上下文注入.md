# 08 归档与上下文注入

> **本类目标**：验证「每一轮对话都被完整归档」与「模型在回答前拿到了该拿的上下文」两件事。归档是可观测性与审计的基础；上下文注入是回答质量的基础。
> **用例数**：12　|　**编号前缀**：`FR-F*`、`FR-H*`、`SES-TC*`
> **执行通道**：F（归档取证，宿主侧）+ A（对话模拟）+ D（出站事件）
> **来源**：`LangGraph编排内核化_功能复现测试用例_V1.md` F/H 组；`Session主体化与WorkItem能力化_测试报告_V1.md` TC10/TC15

## 前置

- 归档目录：`emily-data/session_archives/`。**必须从宿主侧读取**（容器内 `/app/emily-data/session_archives` 不存在，用容器路径判失败会误判）。
- 取证方式：`Get-ChildItem "emily-data\session_archives" -Filter "*.md" | Sort-Object LastWriteTime -Descending | Select-Object -First 3`

## 一、归档用例（`FR-F*`，5 条）

| 编号 | 目标特性 | 操作 | 预期（判定标准） | 断言 | 来源 |
|------|---------|------|----------------|------|------|
| FR-F1 | 轮次归档 | 完成一轮对话后查归档目录 | 出现该会话 md；含「第 N 轮 · 时间」「用户消息」「回复」 | archive_completeness | FR-F1 |
| FR-F2 | 归档内嵌**能力调用清单**（五要素） | 一次业务提问后查归档 | 出现「🔧 能力调用」段：**能力名、参数、成果摘要、触发者、成败** | archive_completeness | FR-F2 / SES-TC10 |
| FR-F3 | 权限快照未降级 | 查归档「会话快照」段 | `level` 与用户一致；授权节点非空；`sop_allow` 非空；`scopes` 非空 | archive_completeness | FR-F3 |
| FR-F4 | 进度事件同源 | 端到端一次业务提问，观察 SSE 出站 | 出站事件含 `progress`（≥1）与 `reply`（=1）；进度文案来自节点映射（如「正在调用能力处理…」） | log_contains | FR-F4 |
| FR-F5 | TTL 归档与段落完整性 | 会话过期后查归档 | 归档文件生成；段落之间换行完整（**历史缺陷**：追加轮次段与头部之间缺换行，形如 `总轮数: 1## 第 1 轮`） | archive_completeness | FR-F5 |

## 四、归档完整性检查清单（人工核对用）

| 检查项 | 通过标准 |
|--------|---------|
| 轮次分段 | 每轮有独立标题与时间戳 |
| 能力段 | 每条能力调用含 能力名 / 参数 / 成果 / 触发者 / 成败 |
| 快照段 | `level`、授权节点、`sop_allow`、`scopes` 均非空 |
| prompt 段 | 含规则书/项目/节点/群上下文注入痕迹，字数非 0 |
| 多用户隔离 | 不同用户各自独立归档文件，**不串上下文** |
| 无第二套存储 | 未新增"能力执行记录"专用表（`grep CapabilityExecution` 应为 0 命中） |
