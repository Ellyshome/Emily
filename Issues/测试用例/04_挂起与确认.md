# 04 挂起与确认

> **本类目标**：验证「信息不全时先问、用户补充后续接」与「写操作需用户确认」两条交互闭环，以及挂起的归属判定与跨进程行为。
> **用例数**：8　|　**编号前缀**：`FR-E*`、`SES-TC*`
> **执行通道**：A（对话模拟）为主，C（回放）覆盖跨步续接
> **来源**：`LangGraph编排内核化_功能复现测试用例_V1.md` E 组；`Session主体化与WorkItem能力化_测试报告_V1.md` TC08/TC09/TC14

## 前置

- **同一 `sender_id` 视为同一会话**（会话上下文由服务端 `SessionPoolManager` 维持）。多轮用例必须保持 `--sender` 一致。
- 挂起状态为**内存态**，容器重启即失效（PRD D3 已书面接受，见 `docs/Manual/技术踩坑备忘录.md §9.3`）。

## 用例

| 编号 | 目标特性 | 操作 | 预期（判定标准） | 断言 | 来源 |
|------|---------|------|----------------|------|------|
| FR-E1 | 能力需补参时挂起并追问 | 发「记一条事件」（缺项目） | 回复为**追问**（如「请补充项目名称」）；挂起态写入检查点 | suspend_resume | FR-E1 |
| SES-TC08 | 缺参提问 → 续接**同一能力**、无需重述 | 轮1 发「帮我记录事件：验证测试-科技城5号楼铺装完成25平米，验收通过」→ 轮2 发「科技城5号楼铺装完成了25平米，验收通过」 | 轮1 归档「⏸ 能力待用户补充」；轮2 归档「✓ 同一能力 成功」，参数含 `[用户补充]` 标记；用户**无需重述** | suspend_resume, archive_completeness | Session TC08 / AC-US-06.1 |
| FR-E2 | 跨进程续接 | 阶段 A 触发挂起 → **重启 emily-core** → 补发项目名 | 新进程仍能读取检查点并续接完成写入；无数据丢失 | suspend_resume, db_effect | FR-E2 |
| FR-E3 | 挂起归属判定（谁发起谁确认） | 非发起者在**同一会话**回复挂起项 | **拒绝**（提示由发起者确认）；挂起态**不被消费** | permission_block | FR-E3 |
| FR-E4 | 写操作二次确认 | 发「删除科技城5号楼的文件」「帮我把上一条事件记录删掉」等写类操作 | 回复为**确认请求或澄清**，**不直接执行**；库内无删除发生 | reply_contains（确认问句）, db_effect | FR-E4 |
| FR-E5 | 待确认事件注入 + 确认消费 | 在存在待确认项时回复「确认」 | 注入待确认上下文并消费确认；待确认项状态由 `pending` → **`confirmed`** | reply_contains, db_effect | FR-E5 |
| SES-TC09 | 确认归位为对话行为（复用既有确认存储） | 发「确认」 | 归档「✓ 能力: confirm_pending 成功」+ 参数 `{"event_no": "EVT-…"}`；DB 该事件 `status=confirmed`；**未新增确认表** | db_effect, archive_completeness | Session TC09 / AC-US-07 |
| SES-TC14 | 挂起重启失效为**已接受缺口** | 挂起后重启容器再追问 | 挂起失效（内存态重建），**重提可正常处理**；不报错、不产生脏数据 | 行为观察 + log_contains | Session TC14 / AC-US-06.4 |

## 执行命令参考

```powershell
$CLI = "uv run python .claude/skills/emy-test/cli.py --managed --llm"

# 挂起 → 续接（同一 sender）
& $CLI --message "帮我记录事件：验证测试-科技城5号楼铺装完成25平米，验收通过" --sender "李景利"
& $CLI --message "科技城5号楼铺装完成了25平米，验收通过" --sender "李景利"

# 确认消费
& $CLI --message "确认" --sender "李景利"
docker exec emily-postgres psql -U emily -d emily -c "SELECT event_no,status,title FROM events ORDER BY created_at DESC LIMIT 3;"

# 归属判定：换一个 sender 在同会话回复挂起项
& $CLI --message "翠湖庭院" --sender "张正宏" --cid "<挂起时的会话号>"

# 跨进程续接：挂起后重启再补参
docker compose -f docker-compose-napcat.yml restart emily-core
& $CLI --message "翠湖庭院" --sender "李景利"
```
