## 2. 系统组织框架：全生命周期节点图

项目运作以**全生命周期节点图**为锚点进行组织：

- 项目按阶段拆分为一系列**节点**（如：方案设计、施工图、施工准备、主体施工、竣工验收等）
- 每个节点有独立的：参与者清单、协作文件库、时限计划、条件需求、成果要求
- 节点之间通过条件需求与产出成果形成依赖链，推动项目流转

### 组织架构模型：公司-人员-节点 三级绑定

```
公司实体
  └─ 人员（每个用户绑定所属公司）
       └─ 参与节点（按公司为分组加入节点任务小组）
```

- **人绑定公司**：每个系统用户必须归属一个公司实体（建设单位、设计单位、总包、分包、监理、供应商等）
- **节点分小组**：每个节点由多家公司的人员共同参与，形成该节点的**任务小组**
- **节点设管理者**：每个节点指定一名或多名管理者（通常是建设单位项目经理或总监理工程师），负责该节点的权限审批与进度把控

### 节点权限模型

**权限以节点为边界进行管控**：

1. **节点可见性**：属于某节点任务小组的成员，才能查看该节点的内容
2. **节点公共文件**：被标记为「节点相关」的文件，该节点所有成员都可见
3. **公司级共享**：同一公司在同一节点的成员，默认共享该公司上传的文件
4. **管理者权限**：节点管理者拥有该节点的全操作权限，可增减成员、审批文件发布

## 3. 会话处理机制：Session + WorkItem 主线

与上述节点图（项目级组织框架）不同，即时消息处理采用独立的 Session 主线架构：

```
用户消息
  ↓
SessionAgent（每会话大脑）
  ├─ 快速通道：问候/感谢/告别 → 直接回复（无 LLM）
  ├─ LLM 意图识别 → SOP 匹配
  └─ 单 SOP / 复合 SOP / 未命中回退 → 创建 WorkItem
  ↓
PipelineBUS（4 节点执行总线）
  ├─ node1: 知识注入（SOP/工具/RAG）
  ├─ node2: 计划生成
  ├─ node3: 工具执行
  └─ node4: 成果总结
  ↓
回复用户
```

- **SessionAgent**：维护每个会话的上下文、用户记忆、权限快照。决定"这条消息要做什么"
- **WorkItem**：单次任务的完整记录，在 4 节点 PipelineBUS 中流转（CREATED → PLANNING → EXECUTING → DONE）
- **PipelineBUS**：声明式 Hook 机制（ALLOW/WARN/BLOCK 三态），支持鉴权、风险、日志等横切关注点

节点图是**组织框架**（管"项目结构是什么"），Session+WorkItem 是**执行机制**（管"每次对话怎么处理"），两者在不同层次协作。

        from emily_core.infrastructure.database.models import Event, Task, Meeting, File

            tasks = session.query(Task.id).count()
            meetings = session.query(Meeting.id).filter(
                Meeting.is_deleted == False,

def _sub_fetch_kb_stats() -> Tuple[dict, Optional[str]]:
    """从 SQLite data/knowledge_base/kb.db 获取知识库存量统计。

    数据源：knowledge_bases 表的 doc_count 和 chunk_count 字段。
    只读模式打开，不存在则标记 unavailable。
    """
    kb_path = _resolve_kb_db_path()

    # 文件不存在 → unavailable
    if not kb_path.exists():
        logger.warning("KB db not found: %s", kb_path)
        return {
            "total_docs": 0,
            "total_chunks": 0,
            "index_status": "unavailable",
        }, None

    try:
        conn = sqlite3.connect(f"file:{kb_path}?mode=ro", uri=True)
        try:
            cursor = conn.execute(
                "SELECT COALESCE(SUM(doc_count), 0), COALESCE(SUM(chunk_count), 0) "
                "FROM knowledge_bases"
            )
            row = cursor.fetchone()
            total_docs = row[0] if row else 0
            total_chunks = row[1] if row else 0

            # 判定索引状态
            if total_docs == 0:
                # 检查文件最后修改时间是否超过 7 天
                mtime = kb_path.stat().st_mtime
                age_days = (time.time() - mtime) / 86400
                if age_days > 7:
                    index_status = "needs_rebuild"
                else:
                    index_status = "normal"
            else:
                index_status = "normal"

            return {
                "total_docs": total_docs,
                "total_chunks": total_chunks,
                "index_status": index_status,
            }, None
        finally:
            conn.close()
    except Exception as e:
        logger.error("_sub_fetch_kb_stats SQLite error: %s", e)
        return {
            "total_docs": _SENTINEL,
            "total_chunks": _SENTINEL,
            "index_status": _SENTINEL,
        }, f"知识库统计获取异常: {e}"

                "meetings": business.get("meetings") if business.get("meetings") != _SENTINEL else None,
                "files": business.get("files") if business.get("files") != _SENTINEL else None,

                "index_status": kb.get("index_status") if kb.get("index_status") != _SENTINEL else None,
            },
            "warnings": warnings,
            "error_message": error_message,
        }

        logger.info(

        return result

def _inject_self_check_data(template: str, data: dict) -> str:
    """将自检数据注入模板，替换 {变量名} 占位符。

    支持的占位符格式：
      - 简单路径：{status} → data["status"]
      - 嵌套路径：{users.total} → data["users"]["total"]
      - 嵌套路径：{knowledge_base.total_docs} → data["knowledge_base"]["total_docs"]

    未匹配的占位符保留原样（不报错）。
    Null 值显示为 "N/A"。
    """
    def _resolve(key_path: str) -> str:
        """解析点分隔的 JSON 路径，返回字符串值。"""
        parts = key_path.split(".")
        current = data
        try:
            for part in parts:
                current = current[part]
            if current is None:
                return "N/A"
            return str(current)
        except (KeyError, TypeError):
            return f"{{{key_path}}}"  # 保留未匹配的占位符

    # 匹配 {xxx.yyy} 或 {xxx} 格式的占位符
    def _replace(match: re.Match) -> str:
        key_path = match.group(1)
        return _resolve(key_path)

    return re.sub(r"\{([a-z_]+\.[a-z_]+|[a-z_]+)\}", _replace, template)


def _build_email_body(data: dict) -> str:
    """根据自检数据生成邮件正文（纯文本）。"""
    lines = [
        f"Emily 系统冷启动自检报告",
        f"═══════════════════════════════════",
        f"检查时间：{data.get('check_time', 'N/A')}",
        f"总耗时：{data.get('check_duration_ms', 'N/A')}ms",
        f"整体状态：{data.get('status', 'N/A')}",
        f"",
        f"--- 用户 ---",
        f"总用户：{_safe_get(data, 'users', 'total')}",
        f"管理员：{_safe_get(data, 'users', 'admins')}",
        f"",
        f"--- 项目 ---",
        f"项目总数：{_safe_get(data, 'projects', 'total')}",
        f"",
        f"--- 业务数据 ---",
        f"事件：{_safe_get(data, 'business', 'events')}",
        f"任务：{_safe_get(data, 'business', 'tasks')}",
        f"会议：{_safe_get(data, 'business', 'meetings')}",
        f"文件：{_safe_get(data, 'business', 'files')}",
        f"",
        f"--- 知识库 ---",
        f"文档：{_safe_get(data, 'knowledge_base', 'total_docs')}",
        f"分块：{_safe_get(data, 'knowledge_base', 'total_chunks')}",
        f"索引：{_safe_get(data, 'knowledge_base', 'index_status')}",
        f"",
    ]
    if data.get("warnings"):
        lines.append("--- 警告 ---")
        for w in data["warnings"]:
            lines.append(f"  ⚠ {w}")
    if data.get("error_message"):
        lines.append(f"--- 错误 ---")
        lines.append(f"  ❌ {data['error_message']}")
    lines.append("═══════════════════════════════════")
    return "\n".join(lines)


def _safe_get(data: dict, *keys: str) -> str:
    """安全获取嵌套 dict 值，None → "N/A"。"""
    current = data
    try:
        for k in keys:
            current = current[k]
        if current is None:
            return "N/A"
        return str(current)
    except (KeyError, TypeError):
        return "N/A"

class ColdStart:
    """冷启动流程编排器。

    静态方法 run() 执行完整冷启动流程：
      1. 自检数据采集
      2. 邮件通知管理员
      3. 世界书 Prompt 生成

    Fail-Open：邮件失败不阻塞，模板缺失用降级方案。
    """

    @staticmethod
    async def run() -> str:
        """执行完整冷启动流程。

        Returns:
            str: 完整的系统 Prompt 上下文文本（世界书 + 注入的自检数据）
        """
        import time as _time
        from self_check import SelfCheck

        t_start = _time.monotonic()
        logger.info("ColdStart: begin")

        # ── 步骤 1: 自检数据采集 ──
        try:
            check_data = SelfCheck.run()
            logger.info(
                "ColdStart: self_check done — status=%s duration=%dms",
                check_data.get("status"), check_data.get("check_duration_ms", 0),
            )
        except Exception as e:
            logger.error("ColdStart: self_check failed: %s", e)
            # 使用空数据占位
            check_data = {
                "check_time": "N/A",
                "check_duration_ms": 0,
                "status": "error",
                "users": {"total": "N/A", "admins": "N/A"},
                "projects": {"total": "N/A"},
                "business": {"events": "N/A", "tasks": "N/A",
                             "meetings": "N/A", "files": "N/A"},
                "knowledge_base": {"total_docs": "N/A", "total_chunks": "N/A",
                                   "index_status": "N/A"},
                "warnings": [],
                "error_message": str(e),
            }

        # ── 步骤 2: 邮件通知 ──
        creds = _build_email_credentials()
        if creds is not None:
            admins = _get_admin_emails()
            email_body = _build_email_body(check_data)
            subject = f"Emily 冷启动自检报告 — {check_data.get('status', 'unknown').upper()}"

            try:
                from emily_core.providers.email.smtp_provider import SMTPEmailProvider
                from emily_core.services.email_service import EmailService
                from emily_core.providers.email.imap_provider import IMAPEmailProvider

                email_service = EmailService(
                    smtp=SMTPEmailProvider(),
                    imap=IMAPEmailProvider(),
                )

                for admin_email in admins:
                    try:
                        result = await email_service.send(
                            creds=creds,
                            to=admin_email,
                            subject=subject,
                            body=email_body,
                            html=False,
                        )
                        if result.success:
                            logger.info("ColdStart: email sent to %s (message_id=%s)",
                                        admin_email, result.message_id)
                        else:
                            logger.warning("ColdStart: email failed to %s: %s",
                                           admin_email, result.error)
                    except Exception as e:
                        logger.warning("ColdStart: email error to %s: %s", admin_email, e)
            except Exception as e:
                logger.warning("ColdStart: email service init failed: %s", e)
        else:
            logger.info("ColdStart: email skipped (no credentials)")

        # ── 步骤 3: 世界书 Prompt 生成 ──
        try:
            template = _load_world_book()
            prompt = _inject_self_check_data(template, check_data)
            logger.info("ColdStart: world book injected (%d chars)", len(prompt))
        except Exception as e:
            logger.error("ColdStart: world book generation failed: %s", e)
            prompt = _FALLBACK_PROMPT

        elapsed = int((_time.monotonic() - t_start) * 1000)
        logger.info("ColdStart: done — total=%dms", elapsed)

        return prompt
