# 独立节点基础模板

## 独立节点基础模板类，共同基类

- 时态流转
    - 一般时态
        - 状态：未启动 → 动作：启动 → 状态：运作中 → 动作：完工确认 → 状态：完工归档
    - 特殊时态
        - 未追踪，此状态只能手动切换。（某节点可能不纳入系统监管）
- 动作来源
    - 动作：启动
        - 节点负责人主动启动
        - 节点条件清单满足后，系统提醒后，节点负责人主动启动
    动作：完工确认
        - 节点负责人主动启动
        - 节点条件清单满足后，系统提醒后，节点负责人主动完工确认
- 固有数据段
    - 节点编号
    - 节点名称
    - 计划开启时间
    - 计划结束时间
    - 实际启动时间
    - 实际结束时间
    - 状态最后更新时间


- 责任部门：外键建设单位部门
- 完工确认岗位
- 工作细分清单列表
- 前置条件列表
- 节点成果列表
- 通用文档表单索引（会议纪要、指令单等）
- 机制-异常处理：转人工核实，具体步骤
    - 阶段1，转新信息录入人，自查错误数据，或坚持提交
    - 阶段2，节点负责人给出处理意见，判定哪个数据错误并标记错误数据条目作废，重新要求提交。或请管理员协助
    - 阶段3，管理员协助处理。

### 表单审批流-基类
    - 表单号（KEY）
    - 审批流
        - 表单提交时间
        - 表单提交人
        - 表单生效时间
        - 表划单批准人
        - 审批意见
        - 审批回复
    - 表单作废
        - 作废时间
        - 作废批准人
        - 作废原因
        - 替代表编号

- 录入约束
    - 节点结束后，只保留备注字段，可逐条录入后备信息，其他字段记录不可更改

## 设计阶段状态机模板，继承自基类
- 承包单位
- 节点启动岗位：默认设计部经理
- 完工确认岗位：默认设计部经理
- 基于甘特图的多子任务进程图标
- 条件清单表
- 设计通用文档表单索引（方案评审表、施工图评审表等）
- 成果清单：施工图
- 节点日志
- 节点待解决卡点


## 成本招采状态机模板，继承自基类
- 测算咨询单位
- 节点启动岗位：默认设计部经理
- 完工确认岗位：默认设计部经理
- 成果清单：成本测算

## 工程阶段状态机模板，继承自基类
- 承包单位、监理单位、分包单位
- 节点启动岗位：默认工程部经理
- 完工确认岗位：默认工程部经理
- 基于甘特图的多子任务进程图表
- 条件清单表
- 成果清单：工程完工、验收报告
- 节点专用文档库
- 工程通用文档表单索引（完工确认单、材料进场单等）
- 节点日志
- 节点待解决卡点
