# 节点状态机
- 关联：
    - 参与单位
        - 承包单位、管理单位、第三方单位（总包、甲方）
    - 条件文件
        - 施工图图纸（给施工单位）
        - 规划图纸条件图（给设计单位）
    - 产出成果文件，（文件结构数据库）
        - 零散完工报告
        - 整套图纸
        - 政府凭证
- 指标分解
    - 如铺装、种植数量
- 记录类
    - 节点关联事件表：外键事件库，事件库有对应的节点字段
    - 日志
- 责任主体：部门，外键建设单位部门
- 前置条件：外键节点成果
- 状态流转
    - 未启动、已启动、已完工归档
- 节点成果：成果文件清单
- 节点编号
- 节点启动时间
- 节点启动批准人
- 节点任务描述

- 节点公共笔记
- 节点完工确认时间
- 节点完工确认人
