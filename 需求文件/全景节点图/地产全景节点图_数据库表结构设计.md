# 地产全景节点图 — 数据库表结构设计

> 本文件配合 `emily-data/baseknowledge/全景节点.md`，描述节点状态机的数据库实现。

---

## 节点表 (`sm_nodes`)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | UUID PK | NOT NULL | 主键 |
| `node_id` | VARCHAR(20) | UNIQUE, NOT NULL | "1.1", "2.1.3" |
| `node_name` | VARCHAR(500) | NOT NULL | 节点名称 |
| `stage_id` | INTEGER | NOT NULL | 1-7 |
| `status` | VARCHAR(20) | DEFAULT 'NOT_STARTED' | 5态 |
| `precondition_score` | INTEGER | DEFAULT 0 | 0-100 |
| `risk_level` | VARCHAR(20) | DEFAULT '正常' | 正常/关注/高风险 |
| `is_milestone` | BOOLEAN | DEFAULT FALSE | 里程碑节点 |

## 阶段表 (`sm_stages`)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | UUID PK | NOT NULL | 主键 |
| `stage_id` | INTEGER | UNIQUE, NOT NULL | 1-7 |
| `stage_name` | VARCHAR(500) | NOT NULL | 阶段名称 |
| `status` | VARCHAR(20) | DEFAULT '未启动' | 3态 |
| `total_nodes` | INTEGER | DEFAULT 0 | 节点总数 |
| `completed_nodes` | INTEGER | DEFAULT 0 | 已完成数 |
| `progress` | INTEGER | DEFAULT 0 | 0-100% |
| `boundary_start` | VARCHAR(1000) | | 阶段进入条件 |
| `boundary_end` | VARCHAR(1000) | | 阶段闭环标志 |

## 依赖表 (`sm_node_dependencies`)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `from_node_id` | VARCHAR(20) | PK | 下游节点 |
| `to_node_id` | VARCHAR(20) | PK | 上游节点 |
| `weight` | FLOAT | DEFAULT 1.0 | 依赖权重 |
| `required` | BOOLEAN | DEFAULT TRUE | 强依赖 |

## 状态变更审计表 (`sm_status_history`)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | UUID PK | NOT NULL | 主键 |
| `node_id` | VARCHAR(20) | NOT NULL | 节点ID |
| `from_status` | VARCHAR(20) | | 变更前 |
| `to_status` | VARCHAR(20) | NOT NULL | 变更后 |
| `operator_id` | VARCHAR | | 操作人 |
| `reason` | VARCHAR(1000) | | 原因 |
| `snapshot` | TEXT | DEFAULT '{}' | JSON快照 |
| `created_at` | VARCHAR | | 时间 |

---

## 状态转移矩阵

```
NOT_STARTED → IN_PROGRESS → COMPLETED (终态)
                          → BLOCKED
                          → DELAYED
BLOCKED → IN_PROGRESS
        → DELAYED
DELAYED → IN_PROGRESS
        → COMPLETED
```
